# ⚙️ Compiler Design Lab (CSE Coursework)

This repository contains C++ implementations of core lexical and syntax analysis algorithms for the **Compiler Design** lab coursework.

---

## 📂 Implemented Algorithms & Tasks

| File                       | Description                                                                                                           | Language |
| :------------------------- | :-------------------------------------------------------------------------------------------------------------------- | :------- |
| `dfa.cpp`                  | Simulation of a **Deterministic Finite Automaton (DFA)** for state transition tracing and string validation.          | C++      |
| `Removecmnt.cpp`           | **Lexical Preprocessor:** Scans raw source files to strip single-line (`//`) and block (`/* ... */`) comments.        | C++      |
| `language_recognizer.cpp`  | **Language Recognizer:** Validates strings against formal grammar constraints (parity check, prefix/suffix patterns). | C++      |
| `input.txt` / `output.txt` | Sample test vectors and output logs.                                                                                  | Text     |
